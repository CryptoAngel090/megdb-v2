# `@repo/ui`

Пакет примитивов (**Button**, **Badge**, **Input**, **Skeleton**) и CSS-токенов для **админки** и витрины **`/ui-kit`** в `apps/web`.

Продакшен-витрина MegDB в основном строится на **`apps/web/src/styles/globals.css`** — см. **`docs/design-system.md`**.

## Экспорты

- `@repo/ui/button`, `badge`, `input`, `skeleton`
- `@repo/ui/tokens/tokens.css`, `@repo/ui/tokens/globals.css`
